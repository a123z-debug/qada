# قاعدة البيانات القانونية - منصة أصول القضاء
## Legal Database - Osool Al-Qada Platform (الإصدار المحدث 2.0)

مرحباً بك في المستودع الهيكلي المطور والمنظم لمواد وأنظمة ولوائح منصة **أصول القضاء**.
تم تحديث الهيكل ليشمل تفصيلاً معمقاً لـ **نظام خدمة الأفراد** و**منظومة قضاء ديوان المظالم بكافة فروعها ولوائحها التنفيذية الإجرائية**، إلى جانب الأنظمة العامة والجزائية:

### ⚖️ التركيز الخاص: نظام خدمة الأفراد ومنظومة ديوان المظالم
- **نظام خدمة الأفراد**: تم تضمين نصوص النظام ومواده الحاكمة للرتب، التعيين، الترقية، البدلات والمزايا المالية (بدل خطر، بدل إرهاب، بدل ترحيل)، وضمانات التحقيق العسكري، وربطه باختصاصات ديوان المظالم بموجب المادة (13) في نظر دعاوى حقوق العسكريين والسوابق القضائية الراسخة في هذا الشأن.
- **فروع ديوان المظالم**: تنظيم متكامل يغطي المحكمة الإدارية العليا، محاكم الاستئناف الإدارية الموزعة جغرافياً، المحاكم الإدارية الابتدائية ودوائرها (الإدارية، التأديبية، الفرعية)، مع كافة اللوائح التنفيذية التخصصية وقواعد الترافع عبر منصة معين.
